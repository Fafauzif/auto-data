## Capture notes

- The source was the verified local production build of the responsive Digiroom KEY overlay. Desktop viewport shots use 1920 × 1080. Mobile shots use a 390 × 844 CSS viewport with 2× pixel density. Companion dimensions vary by content.
- The screenshots use sample demo accounts and walkthrough records. Photos of devices and real customer data are outside this archive. Dates were held consistent for the main walkthrough, with the browser date advanced for the expired-offer screen.
- The maps use the bundled local atlas, with both network layers captured for all four markets. The counts describe **modeled origins** in the oil-service access study. They are not market demand or observed customer visits. Keep the visible map attribution if cropping.
- Native browser and operating-system pickers sit outside the web page, so the workspace selection is documented through its resulting workspace screens. The QR and share-link screenshots demonstrate the preview build and contain local demo links. The WhatsApp frame shows the in-app draft.
