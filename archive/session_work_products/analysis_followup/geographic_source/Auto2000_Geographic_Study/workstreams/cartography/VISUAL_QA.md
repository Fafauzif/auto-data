# Cartography QA

The generated figure registry contains 27 analytical figures. Input tables remain authoritative. Static PNG review inspected representative examples of each major layout: provider maps, screened origin-gap maps, returned-route maps, single-route detail figures, travel-access curves, official oil-channel location panels, candidate-definition sensitivity and branch-influence charts. Clipped/overlapping labels in initial route layouts were corrected, the provider key was shortened and wrapped, scale bars were moved out of origin squares, and the screened-gap map gained explicit triangle/cross/route-trace legends. Fixed cross-market gap colour limits are stated in captions. The three-route high-resolution outputs remain for detailed inspection; the PDF has a more readable single-route variant.

The HTML explorer is self-contained and has no external tile/CDN dependency. Its embedded data and JavaScript were executed in a Node VM with a lightweight DOM harness across 48 combinations of four markets, two snapping scenarios and six origin-display modes. Provider inspection, layer hiding, zoom, pan and reset handlers passed. This is programmatic interaction QA, not a browser render or user test. The attempted Chromium render was blocked before page load by workspace socket/process restrictions; no rendered-browser validation is claimed.

Maps preserve uncertainty. Repair/service candidates do not establish independent ownership or Toyota/job compatibility. An official workshop listing does not establish model-specific current capability or capacity. Grey crosses on the primary gap maps are missing paired results after the 250 m snapping screen, not zero travel burden. Route illustrations use returned all-routed examples and display maximum endpoint displacement; their selected extrema/median are not representative customer journeys.
