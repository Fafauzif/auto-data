# Reproducing this workstream

Dependencies used: Python3, pandas, numpy, scikit-learn, matplotlib, lxml and the shared `public_http.py` transport. Tesseract and Poppler assisted visual source inspection but did not produce validated tables automatically. Environment-specific private cache paths are resolved relative to the research root.

1. `acquire.py NAME URL` fetches a public source through the shared scheduler and records URL/status/hash/requestID. It stores source bytes under `private_cache/datasets/`. Consult `acquisition_log.jsonl` for exact source URLs and names, not guessed URL patterns. Initial manual metadata fetches predated the shared scheduler and are explicitly logged without a shared requestID.
2. `bps_collect.py` fetches BPS yearly source pages and decodes their public RSC table objects. It expects the previously fetched2024page at `bps_vehicle_stock.html`; that URL is in the log. It asserts requested and actual year match, preserves source footnotes, and writes long-format numeric observations.
3. For SPKLU, acquire the observed catalog/file/folder metadata URLs in the log. `spklu_collect.py` uses the source's actual file IDs and validates every downloaded file against its published hash. Alternatively, copy the exact licensed source files from `raw_licensed_data/SPKLU_CC_BY_NC_3_0/data/` and `/reference/` into the privatecache names used by analysis, preserving attribution. `spklu_analyze.py` computes source-grain audits and independent haversine distances, then exports only useful summaries.
4. The five current official branch directions in `site_branch_identity_probe.json` were collected by the parent process. `geo_sensitivity.py` keeps source coordinates untouched and computes a separately labeled candidate-location scenario. Repeating after a source update can legitimately change results. This is not a current station-location verification service.
5. `market_transcribe.py` uses manually read values from the exact hashed graphic files. Reacquiring the same URL does not guarantee unchanged bytes. Visually inspect every value and compare sums; retain the2026chart/narrative discrepancy rather than forcing agreement. The script is a reproducible transcription record, not an automated full-market data scraper.
6. `casa_calibrate.py` uses the acquired CASA train/valid/testCSV files only in privatecache. It checks normalized text overlaps and removes train duplicates/heldout overlaps before fitting a fixed baseline. It exports metrics, not original reviews. Source files must be reacquired from logged URLs; no arbitrary remote code is executed.
7. `igar_collect.py` uses the observed public Mendeley file metadata and verifies both file hashes. `igar_analyze.py` matches on six shared fields, checks exact duplicate counts and exports nontext features plus label-view comparisons. Raw rows are not assumed independent across views. Original files are available in the separately licensed raw appendix. The later conditional tables group the nontext feature export by translation-missing, stars and source confidence bands; all are disagreement summaries, not accuracy.
8. `dataset_figures.py` regenerates original analytical figures from derived CSVs. No official report screenshots are redistributed as original artwork.

The raw appendix contains exact third-party bytes where indicated; our CSV/JSON outputs are transformed or derived and identify their input source. Internet access, source terms and current availability must be respected at rerun. Credentials, sessions, source user documents and private customer systems are not required or included.
